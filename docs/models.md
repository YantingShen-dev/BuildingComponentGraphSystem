# Included model

| Item | Value |
|---|---|
| Checkpoint | `bcgs/assets/energy_merged_EUIGCN9.pth` |
| Architecture | Original two-layer residual Enhanced GAT, four attention heads, max pooling |
| Input | 26 encoded component features and physical connections |
| Output | One building-level annual EUI value, kWh/(m²·year), as defined by the original training pipeline |
| Default device | CPU |
| Core paper | [Shen et al., Energy & Buildings](https://doi.org/10.1016/j.enbuild.2025.116584) |

The checkpoint is carried over unchanged from the original repository. Its input ordering, model parameter names, and pooling are preserved. It has not been retrained or calibrated during the toolkit reorganization.

The ENB study used parametrically generated residential buildings and EnergyPlus under Changsha climatic conditions. The package does not accept weather as a conditioning input, and the included checkpoint is not a general model for every climate or building type. Validate performance on your target data before interpreting predictions as project estimates.

The bundled example is the original repository's `input/0` building, reduced to the 16 input fields and adjacency matrix. Hourly outputs and energy labels are omitted. Its approximately 508.0457 prediction is recorded solely as a regression reference. No new claim of predictive accuracy follows from this check.

## What is not bundled

- Full ENB training data, data generation software, or a verified training reproduction.
- CAADRIA building / thermal-zone / surface models and consistency experiments.
- AEI visual-semantic models or UFUG VAE / clustering workflows.

Links to these papers appear in the [README](../README.md#papers-and-citation). They document related methods, not additional runtime capabilities.

## Explanations and optimization

The package exposes standard GNNExplainer attribute/edge masks. The historical web implementation combined masks with additional perturbation calculations. These outputs are different, so existing paper plots should not be presented as regenerated by the new command.

Material optimization now uses the same equivalent-conductivity calculation for scoring and exporting designs. The old implementation multiplied total thickness by layer resistance during evaluation but divided during export. Correcting that inconsistency changes optimization results; it does not change prediction for an unchanged building.

The finite NSGA-II search compares predicted EUI and illustrative material cost. It does not implement the paper's full EnergyPlus / daylight / Wallacei optimization experiment.
